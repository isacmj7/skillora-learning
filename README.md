# Skillora Learning

An India-first, AI-powered learning and career platform that helps engineers prepare for senior technical interviews: structured courses, AI mock interviews (text and voice), a system-design canvas, adaptive study plans and a shareable skills profile.

> **Status: design and planning.** This repository contains the product and engineering design documents. There is no application code yet. Release 1.0 (web) is in preparation.

## What is in this repository

| Path | Contents |
|---|---|
| `docs/01_High_Level_Design/` | Product strategy and roadmap, master specification, India market and compliance, engineering standards |
| `docs/02_Low_Level_Design/` | Admin portal, learning experience, credentials, resume studio |
| `docs/03_Prompts/` | AI-agent build prompts for the web and mobile apps |
| `docs/04_Future_Scope/` | Future directions (not in Release 1.0) |
| `docs/05_Release_1_0/` | Release 1.0 scope, audience policy, engineering ADRs and spikes, 19 course syllabi, integration documents |

## Release 1.0 at a glance

- Web only: learner portal and admin portal.
- A 19-course curriculum for Senior Python Backend and AI Engineer roles.
- Interview Master: text and voice mock interviews with rubric-based feedback.
- Adaptive study plan, system-design canvas and company-specific practice packs.
- Verified skill badges and an opt-in public profile.
- Adults only (18+).
