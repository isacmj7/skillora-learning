# 02 — Low-Level Design

Detailed specifications for individual features and subsystems. Answers **how each part works**: workflows, rules, data models, admin controls, phasing, definitions of done.

| Subfolder | Contents |
|---|---|
| `01_Admin_Portal` | Admin control plane: content, knowledge, assessments, execution (Python/SQL), AI/providers, users, commerce, compliance |
| `02_Learning_Experience` | Visual Learning System: diagrams, flows, level-adaptive teaching, interactive visuals |
| `03_Credentials` | Skill badges, certificates, verification, sharing |
| `04_Career_Resume_Studio` | AI job-ready resume and career documents |

Future low-level designs (e.g. Interview Engine internals, Coding/SQL sandbox detail, Billing adapter, Notification service, data model/ERD, API contracts) get a new numbered subfolder here.

Future-scoped designs: corporate upskilling is in `../04_Future_Scope/`. Recruiter screening (Skillora Screen) is a separate product in `../../02_Skillora_Screen/`.
