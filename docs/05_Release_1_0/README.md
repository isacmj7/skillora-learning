# 05 — Release 1.0 (web-only launch)

**The authoritative home for everything specific to Skillora Learning Release 1.0.** Where another document conflicts with this folder on 1.0 scope, this folder wins.

Release 1.0 = **web only** (Learner Portal + Admin Portal), curriculum for **Senior Python Backend / AI Engineer** interview readiness, **Interview Master with text + voice**, advanced system-design canvas with auto-evaluation, adaptive engine, last-minute mode, company packs. **Billing Lite (time-boxed passes, voice credit packs, GST invoices, refunds) and a 7-day free trial (extendable to 14) are in 1.0** (confirmed 2026-10-22; see `01_Scope/Skillora_Learning_Release_1_0_Billing_Lite_and_Trial_Specification.md`). **Adults only (18+, Higher Secondary completed) per `01_Scope/Skillora_Learning_Release_1_0_Audience_and_Eligibility_Policy.md`.** **Public Profile Lite (opt-in public profile, verified badges, share images, embeddable badges) is in 1.0** (see `01_Scope/Skillora_Learning_Release_1_0_Public_Profile_Lite_Specification.md`). Resume Studio, mobile apps, OTP login, recurring billing and subscriptions are 1.1+.
